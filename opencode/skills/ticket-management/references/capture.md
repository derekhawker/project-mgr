# Capture and Clarify

Check the canonical Workspace ticket directory for an existing same-intent
ticket before creating one. Save a new ticket as `<slug>.md` with `draft` status.
Preserve the user's observation, uncertainty, and why it might matter; do not
invent requirements, scope, acceptance checks, architecture, or decisions.

Draft status permits ongoing clarification and grooming. Refine the canonical
Markdown ticket as the user supplies context. Keep its status `draft` until
approved work begins or it is cancelled.

Completion criterion: the idea is durable, searchable, and recognizably the
user's idea without invented decisions.
